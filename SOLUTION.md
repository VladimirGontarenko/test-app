## Решения

**Куда отнёс матчи с другими статусами.** В данных четыре статуса — `finished`, `scheduled`, `live`, `postponed`, а фильтров три. В «Завершённые» попадают только `finished`. В «Предстоящие» — все остальные (`scheduled`, `live`, `postponed`): матч ещё не завершён, значит, для пользователя актуален. `live` («идёт сейчас») логичнее видеть среди предстоящих, чем среди завершённых — он ещё не закончился.

**Неочевидные случаи в данных:**
1. **`startsAt: null`** у матча m7 (`postponed`). `new Date(null)` дал бы `1970-01-01`, поэтому добавил явную проверку: если `startsAt` пустой или невалидный (`NaN`), показываю «Дата уточняется».
2. **`score: null`** у `scheduled` и `postponed` — счёт не показываю. При этом `score: { home: 0, away: 0 }` у `finished` (m2) — валидный счёт 0:0, он отображается. Проверка `if (!match.score) return null` отличает `null` от объекта с нулями.
3. **`minute` есть только у `live`** (m4) — у остальных статусов поля нет. Проверяю `item.status === 'live' && item.minute != null`; `!= null` ловит и `null`, и `undefined`.
4. **Даты в UTC (`Z`)** — `toLocaleString` переводит в локальный часовой пояс автоматически, отдельная конвертация не нужна.
5. **`RefreshControl` на web не работает** — жест перехватывает браузер. Поэтому добавил явную кнопку «Обновить». `RefreshControl` оставил: на мобильном через Expo Go он тоже работает.

## Баги из части 2

1. **Звёздочки:** в `useFavorites` было две ошибки. Первая — `isFavorite` возвращал `Boolean(favorites.indexOf(id))`: `indexOf` отдаёт `-1`, если матча нет, а `Boolean(-1) === true` — поэтому все звёзды горели. И наоборот, у матча с индексом `0` `Boolean(0) === false`, звезда гасла — вот «непредсказуемость». Исправил на `favorites.includes(id)`. Вторая — `toggle` мутировал массив через `push`/`splice` и передавал в `setFavorites` тот же reference: React сравнивает через `Object.is`, видит тот же объект и перерисовку пропускает. Исправил на иммутабельное обновление (`filter` / spread), чтобы создавался новый массив.

2. **«Обновлено N сек назад»:** в `setInterval` было `setSeconds(seconds + 1)`. `seconds` захватывался замыканием из первого рендера (`0`), поэтому каждая секунда ставила `0 + 1 = 1` — счётчик навсегда застревал. Плюс `useEffect` имел пустые зависимости `[]`, поэтому не перезапускался при смене `since` — счётчик не сбрасывался после обновления. Плюс не было `clearInterval` — таймер утекал. Исправил: `update()` считает `Math.floor((Date.now() - since.getTime()) / 1000)` — реальную разницу от `since`; `useEffect` зависит от `[since]`, при обновлении перезапускается и сбрасывается на 0; добавил cleanup `return () => clearInterval(id)`.

## Как я использовал ИИ

Использовал ChatGPT для генерации начального каркаса `MatchesScreen`, подсказок по фиксам багов и структуре `SOLUTION.md`. Самостоятельно проверял каждый шаг в браузере: считал количество матчей в каждом фильтре, проверял счёт у `finished` и его отсутствие у `scheduled`, «Дата уточняется» у `postponed`, тиканье счётчика и его сброс при обновлении, поведение звёзд по одной.

**Случаи, где ИИ был неполным или неверным:**

1. **`RefreshControl` для обновления.** Изначально ИИ предложил использовать `RefreshControl` в `FlatList` как «pull-to-refresh» — но в React Native Web этот жест не работает, браузер перехватывает его для своей перезагрузки страницы. Обнаружил это, когда потянул список вниз в браузере и ничего не произошло. Пришлось явно просить добавить кнопку «Обновить»; ИИ согласился, что это его недоработка.

2. **Порядок `git add` и `git commit`.** На шаге с коммитом ИИ дал команду `git commit` без предшествующего `git add`, и коммит упал с «no changes added to commit». Тут уже моя ошибка — надо было выполнять команды по порядку; но и в подсказке ИИ не подсветил, что staging пуст. Пришлось переспрашивать, что делать.

3. **Плейсхолдер в `config.ts`.** В исходном шаблоне в `config.ts` стоял `OWNER/REPO` — ИИ сразу сказал заменить, но я по инерции сохранил файл, не обратив внимания на строку. Пришлось возвращаться к этому шагу, когда матчи не грузились. В следующий раз буду читать код внимательнее, а не только следовать подсказкам.
